# 🍦 Ice Cream Revenue Prediction Using Machine Learning

## 📌 Project Overview

The **Ice Cream Revenue Prediction** project is a Machine Learning application that predicts ice cream sales revenue based on temperature data. The project demonstrates how Machine Learning techniques can be used to analyze the relationship between temperature and revenue and make predictions using a trained regression model.

The application provides a simple, user-friendly interface where users can enter a temperature value and obtain a predicted revenue.

## 🎯 Objectives

- Predict ice cream revenue using Machine Learning.
- Understand the relationship between temperature and ice cream sales.
- Apply regression techniques to a real-world prediction problem.
- Build and deploy a Machine Learning web application.
- Provide an interactive interface for making predictions.

## 🤖 Machine Learning Approach

5. **Model Training:** Train a regression model using the prepared dataset.
